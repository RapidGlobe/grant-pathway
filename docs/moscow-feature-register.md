# MoSCoW Feature Register — Grant Pathway v1

**Tier:** 2 — Check if relevant to the task
**Volatility:** Medium
**Update when:** Any feature added, removed, promoted, or demoted between Must/Should/Could/Won't

**Version:** 1.14
**Last updated:** 2026-07-11

This document consolidates the MoSCoW priority for all 48 functional requirements in Grant Pathway v1. It is the single authoritative reference for feature scope and is used directly by the PRD.

Priorities are derived from the BRD (Section 9), PRD decision records, screen requirements, and email notifications specification. Where the screen requirements differ from the BRD, the screen requirements take precedence as the more recent and detailed specification — these divergences are noted.

## 9.6 AI Draft Answer Generation

| Ref   | Requirement (summary)                                                                                                       | Priority      | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ----- | --------------------------------------------------------------------------------------------------------------------------- | ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| FR-28 | Charity writes draft answers section by section; AI assists with structure and clarity on request only                      | **Must Have** | **Revised 2026-05-28.** Original requirement was "generate draft answers automatically". Replaced with charity-authored Q&A model: the charity writes all content; AI may improve structure/clarity of a written answer on request ("Help me improve this"). AI never generates answers from scratch. See STEP4-REDESIGN-PROPOSAL.md                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| FR-29 | Word limits and character limits auto-extracted from funder guidelines; displayed alongside each section/question           | **Must Have** | **Revised 2026-05-28; extended 2026-05-29 (BD-05).** Both word limits and character limits are supported (`limit_type: words \| characters \| none`). The AI extracts the limit type and value for each question; the Step 4 counter displays "X / N words" or "X / N characters" as appropriate.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| FR-30 | Per-section AI refine uses the charity's own answer text; may not add facts or change claims; corrects spelling and grammar | **Must Have** | Replaces old "draft generation uses question + charity profile". AI only refines a written answer — it does not write from scratch. **Updated 2026-06-01:** spelling and grammar correction added to refine prompt; always corrects spelling even for very short answers. **Updated 2026-06-04 (D-LBF-02):** Over-limit hard stop introduced. The "Approve this answer" button is now hidden when an answer exceeds the word/character limit. An over-limit message is displayed: "Please trim it or use AI to bring it within the limit before approving." The previous "warn but allow" behaviour (where the user could approve an over-limit answer) has been removed. This decision was made because grant portal systems uniformly reject over-limit submissions, so allowing approval would give false confidence. AI assist remains available when over-limit, as the refine prompt instructs the AI to compress to fit. **Updated 2026-07-04 (PDR-AI-006):** LLMs cannot reliably hit an exact word/character count when compressing — found live during Clothworkers testing (a 200-word answer against a 50-word limit was refined to 60 words, still over). When the AI's suggestion is still over the limit after refining, a conditional inline message will be shown naming the shortfall and prompting the user to trim further or retry (not yet implemented — see PDR-AI-006 for exact wording and implementation status). User guide Section 7 wording updated to stop overstating this as guaranteed. |
| FR-31 | Budget sections/questions flagged in amber; AI assist disabled on budget sections                                           | **Must Have** | **Revised 2026-05-28.** Original "flag draft exceeding word limit". Now: budget questions/sections are visually distinct; AI assist is disabled; user enters own figures                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| FR-45 | Question-level typing: each extracted question carries a `question_type` (BD-04)                                            | **Must Have** | Types: `narrative \| data_entry \| financial \| dropdown \| date \| file_upload`. Narrative questions show a writing card. Data-entry and financial questions are pre-filled from the charity profile. Dropdown, date, and file_upload questions are displayed as read-only reminders only. Replaces funder-level type as the mechanism for question handling. **Not built as described — see ADR-DATA-006 (2026-07-05).** In practice, only `narrative` is ever extracted; the AI extraction prompt discards every other question type entirely rather than classifying it. A nine-funder review found this mechanism too narrow in twenty distinct ways. `ADR-DATA-006` supersedes this FR's mechanism with a typed item-graph model (`docs/BRD plus decisions Mark Two/clean-slate-design-proposal.md`) — not yet built; see the linked build plan. This FR should be revised or retired once that work lands, not before.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| FR-46 | Three-tier funder coverage model displayed to the user (BD-07)                                                              | **Must Have** | Tier 1 (Full — narrative questions, profile pre-fill), Tier 2 (Partial — narrative subset of a portal form), Tier 3 (Guidance — free-form narrative document), intended for display on the new-application screen, Step 3 summary card, and export screen. **Not built — see `docs/BRD plus decisions Mark Two/BRD-Grant-Pathway-v0.6.md` Section 3.3 (confirmed 2026-07-04) and BD-07 in Section 10.** The `funders` table (`supabase/migrations/20260601000000_add_funders_table.sql`) has no tier/coverage-level column — only `name`, `funder_type` (`structured`/`narrative`), `grant_range`, `guidelines_url`, `is_active`. No "Tier 1/2/3" or "Full/Partial/Guidance coverage" wording appears anywhere in the app. What was briefly built instead was an unrelated, simplified two-value "Structured"/"Narrative" picker badge (from the `funder_type` DB column, introduced later by DR-FD-001) — not the tier model this FR describes — and that badge has itself since been retired (2026-07-04, DR-FD-001 v1.2, BD-08). The three-tier model remains a useful internal concept for test planning (`docs/Test Plans/TEST-DASHBOARD.md`) but is not user-facing. This FR should be revised or retired once a decision is made on whether to build a genuine coverage-level display — it is an open question, not a decided-and-unbuilt feature to simply "finish."                                                                                                                                             |
| FR-47 | Eligibility mismatch detection — hard stop on Step 3 when AI detects clear charity/funder mismatch (DR-EL-001)              | **Must Have** | **Added 2026-06-02.** If the AI detects that the charity's profile clearly does not meet the funder's eligibility criteria, a red warning card is shown prominently on Step 3. The Continue button is hidden. The user must acknowledge the warning, which sets the application status to `mismatch` and returns them to the dashboard. No override path exists. Escape hatch: user corrects their charity profile and creates a new application.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
