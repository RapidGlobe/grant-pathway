# DR-PS-001 — Grant Application Pain Points

## Question

What specific grant application pain points will the app solve?

## Context

Understanding which pain points the app targets determines the core feature set and where development effort is focused. UK charities commonly struggle with: finding relevant grants, understanding eligibility criteria, writing compelling applications, tracking deadlines across multiple funders, managing reporting obligations, and reusing content across applications. Choosing a focused set of pain points prevents scope creep and ensures the app delivers real value rather than being a shallow solution to many problems.

## Options

- **Option A: Discovery** — Help charities find grants they are eligible for
- **Option B: Writing** — Help charities write and structure application content
- **Option C: Tracking** — Help charities manage deadlines and application pipelines
- **Option D: Reporting** — Help charities produce post-grant impact reports
- **Option E: Combination** — Address multiple pain points (specify which)

## Decision

**Option B: Writing** — The app will help charities write and structure grant application content using AI.

## Rationale

AI delivers the most transformative value on the writing task. Small charities consistently find the writing burden — not finding grants — to be the primary obstacle. A writing-focused tool requires no dependency on a live grant database, reducing ongoing operational complexity. This allows a focused v1 to be built and delivered quickly, with discovery and other pain points considered for future phases.
