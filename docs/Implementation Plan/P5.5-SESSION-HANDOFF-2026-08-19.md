## Where things stand in one paragraph

`P5.5`'s production runs started and were stopped deliberately after four defects, **three of which were environment divergences rather than product bugs**. `D-018`: production's AWS secret did not match its access key ID, so **no AI feature worked on production at all**. `D-020`: the `authenticated` role had no DML privileges on five tables, so **no signed-in user could read or write anything** — the dashboard's empty state was a permission error. `D-016` and `D-019`: the code discarded the underlying errors in both cases, which is why neither had ever surfaced. Both root causes are now repaired and the repairs are committed. **WJ's decision: audit the environment before restarting `P5.5`, rather than discovering the rest of these one test at a time.**
